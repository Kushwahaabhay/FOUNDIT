# Images Directory

Place app images and assets here.

## Recommended Assets:
- App logo (PNG, 1024x1024)
- Splash screen background
- Empty state illustrations
- Onboarding images (optional)

## Creating App Icon:
1. Design 1024x1024 icon in Canva/Figma
2. Use https://appicon.co/ to generate all sizes
3. Replace icons in `android/app/src/main/res/`

## Placeholder Images:
For testing, you can use placeholder images from:
- https://placeholder.com/
- https://picsum.photos/
