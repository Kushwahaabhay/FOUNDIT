# Fonts Directory

## Required Fonts

Download Poppins font family from Google Fonts:
https://fonts.google.com/specimen/Poppins

### Files Needed:
1. `Poppins-Regular.ttf`
2. `Poppins-Medium.ttf`
3. `Poppins-SemiBold.ttf`
4. `Poppins-Bold.ttf`

### Installation Steps:
1. Go to https://fonts.google.com/specimen/Poppins
2. Click "Download family"
3. Extract the ZIP file
4. Copy the following files to this directory:
   - `Poppins-Regular.ttf`
   - `Poppins-Medium.ttf`
   - `Poppins-SemiBold.ttf`
   - `Poppins-Bold.ttf`

### Alternative:
If you don't want to download fonts, you can use the default system font by removing the `fontFamily: 'Poppins'` lines from `lib/src/core/theme.dart`.
