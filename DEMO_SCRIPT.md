# FOUNDIT Demo Script (2 Minutes)

## Preparation
- Have app installed on Android device
- Ensure internet connection
- Have college email ready
- Prepare sample item to post

## Scene 1: Splash & Login (20 seconds)

**Action:**
1. Open FOUNDIT app
2. Show splash screen with glassmorphism effect
3. Tap "Sign in with Google"
4. Select college email account
5. Show profile completion screen

**Narration:**
"Welcome to FOUNDIT, a smart campus lost & found system for GCET. The app features a beautiful glassmorphism UI. Let's sign in with our college email - only GCET students can access the platform for security."

## Scene 2: Browse Feed (30 seconds)

**Action:**
1. Show main feed with glass cards
2. Scroll through lost/found items
3. Toggle between "All", "Lost", and "Found" tabs
4. Pull to refresh
5. Use search bar to find specific item

**Narration:**
"Here's the main feed showing all lost and found items on campus. Each item is displayed in an elegant glass card with the image, title, category, and location. We can filter by status - Lost or Found - and search for specific items."

## Scene 3: Item Details & Contact (30 seconds)

**Action:**
1. Tap on a Lost item card
2. Show hero animation to full screen
3. View item details (description, location, time)
4. Tap "WhatsApp" button
5. Show WhatsApp opening with pre-filled message
6. Go back and show "Call" and "Email" options

**Narration:**
"When we tap an item, we see full details with a smooth hero animation. The owner's contact information is protected - we can reach them via WhatsApp, phone call, or email. The app opens WhatsApp with a pre-filled message about the item."

## Scene 4: Post New Item (30 seconds)

**Action:**
1. Tap the floating action button
2. Toggle to "Found"
3. Fill in title: "Blue Wallet"
4. Select category: "Wallet"
5. Select location: "Library - 2nd Floor"
6. Add description: "Found near the entrance, contains ID cards"
7. Tap "Gallery" and select image
8. Add phone number (optional)
9. Tap "Post Item"
10. Show success message and return to feed

**Narration:**
"Posting an item is simple. We toggle between Lost or Found, add a photo from camera or gallery, fill in the details - title, category, location, and description. We can optionally add our phone number. Once posted, it appears in the feed instantly for all students to see."

## Scene 5: Admin Dashboard (10 seconds)

**Action:**
1. Tap profile icon
2. Show admin badge
3. Tap admin panel icon
4. Show statistics (total posts, lost, found, resolved)
5. Demonstrate delete post action

**Narration:**
"For administrators like our mentor Dr. Anju Chandna, there's a dedicated dashboard showing statistics and the ability to moderate posts - marking items as resolved or removing spam."

## Closing (10 seconds)

**Action:**
1. Return to feed
2. Show app logo

**Narration:**
"FOUNDIT makes it easy for GCET students to reunite with their lost belongings. Secure, fast, and beautifully designed. Thank you!"

## Recording Tips

1. **Screen Recording:**
   - Use Android's built-in screen recorder
   - Or use AZ Screen Recorder app
   - Record in 1080p, 30fps

2. **Audio:**
   - Record narration separately for clarity
   - Use a quiet room
   - Speak clearly and at moderate pace

3. **Editing:**
   - Use CapCut or Adobe Premiere Rush
   - Add background music (soft, non-intrusive)
   - Add text overlays for key features
   - Keep transitions smooth

4. **Duration:**
   - Aim for 1:45 - 2:00 minutes
   - Each scene should flow naturally
   - No dead time or long pauses

## Common Issues During Demo

**Issue:** App crashes
**Solution:** Have backup recording ready

**Issue:** Slow internet
**Solution:** Pre-load feed before recording

**Issue:** No test data
**Solution:** Create 5-10 sample posts before demo

**Issue:** WhatsApp not installed
**Solution:** Install WhatsApp before demo
